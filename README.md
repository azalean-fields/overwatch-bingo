# overwatch-bingo
a super simple bingo i put together in html and a few lines of css and js. predominantly created for overwatch gaming sessions with my friends (hence the inside jokes) but can be customized to whatever you like. 

## Usage
download the repo as a zip, extract it and open the html file in your browser of choice.

## Customization
the entire bingo is stored in a table in a div, while the style and script are in their own files. from there you can change it to your needs
